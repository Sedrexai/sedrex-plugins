# Sedrex plugins

Plugins for Sedrex: bundles of skills, guidance and the apps they work with, one for each kind of work - sales, finance, legal, marketing, data, customer support, product management, engineering, design, operations, human resources, research and more.

In Sedrex, open **Customize > Plugins > Discover**, add **Sedrex plugins**, then press **+** on a plugin. Its skills become available in every chat (as `/plugin:skill`), and Sedrex suggests which apps to connect so it can use them.

Each plugin is a folder with `.sedrex-plugin/plugin.json`, its skills under `skills/`, and the servers it works with in `.mcp.json`. The list of plugins is `.sedrex-plugin/marketplace.json`.
